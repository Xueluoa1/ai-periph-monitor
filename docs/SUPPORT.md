[操作手册](USER_GUIDE.md) · [完整型号与 USB ID 细表](DEVICE_MATRIX.md) · [验证结果](VALIDATION.md)

**必须分别看电量、DPI、回报率和灯光。已识别名称、已实现协议、模拟测试通过、真实设备读到数据、真实设备写入成功，是不同状态。** 本项目没有逐型号实测全部设备。共享 USB ID、同品牌、相似外形都不能单独证明兼容。

## 既有品牌与协议通道概览

下表是范围导航，不是“品牌全型号支持”承诺；精确 USB ID、档位范围、连接方式和灯区限制见完整细表。

| 品牌 / 型号范围 | 主要已接入能力 | 限制 |
| --- | --- | --- |
| ASUS / ROG / TUF | 精确型号 DPI、回报率、部分灯区；有效协议回复时读电量 | 例如 Chakram/X、Gladius III、Keris/AimPoint/II Ace、Pugio II、Spatha X、Impact II Wireless、Harpe Ace/Mini、TUF M4；有线型号没有电池 |
| ATK / VXE / VGN | 部分 Compx / Nordic 电量；精确型号 DPI、回报率 | 包括 X1 Ultra/Pro Max、F1 Ultimate 2.0、A9 Plus NearLink、R1 Pro Max、R1 星闪；共享接收器须进一步识别 |
| Logitech 罗技 HID++ 2.0 | 电量或原生电压、当前 DPI、支持的回报率与灯区 | 由设备特性能力决定；电压不伪造百分比，部分灯区仅设置，板载模式限制见细表 |
| Razer 雷蛇 | 适配表所列型号的 DPI、回报率；部分电量/灯光 | 按精确 PID 和报文确认；不是所有型号有 RGB，纯有线无电量 |
| MCHOSE 迈从 | A5 Pro Max 等精确通道与目录型号配置 | 旧 A7/M7 电量通道不能直接套新型号设置协议；G7 共享身份需核实 |
| LAMZU 兰族 | 已列 Atlantis 协议通道电量、DPI、回报率 | 共享 ID 不能直接区分 Atlantis/Thorn/Maya/Paro；分轴不同档位限制修改 |
| Scyrox V8 | 电量、DPI、回报率 | 握手确认身份；灯光未接入 |
| Pulsar | 特定 report-8 通道 DPI、回报率、部分接收器指示灯 | 须识别身份及连接状态；不套用其他 3554 接收器公式 |
| WLmouse 万灵 | 细表精确型号 DPI/回报率，部分页面式电量；Beast X 4K 档位色 | 不代表所有目录型号都有电量；接收器能力限制最高回报率 |
| Endgame Gear | OP1w/XM2w 4K 及 v2 电量、DPI、回报率 | 设备按键切档；v2 玻璃模式可能禁止改率，无通用 RGB |

| AJAZZ 黑爵 | NJ07/NJ08/MC/Pro 部分电量、DPI、回报率；部分键盘电量 | A8A4/A8A5 身份能力不同；键盘灯光不自动获得支持 |
| AULA 狼蛛 | F87 Pro V2D 及细表已列共享接收器键盘电量 | 必须匹配接口并收到有效回复；无通用键盘灯光 |
