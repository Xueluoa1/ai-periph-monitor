# 2026-11-24：反馈修复与 ATK A9 Ultimate+ 日志适配

主程序 v1.0.2、诊断工具 v1.5.0 不变；构建标识 `20261124-a9-feedback`。新构建包含此前所有修改。

## 两项反馈

- 迈从 M HUB V3 的连接状态原先只接受 1，会过滤状态 2。现同时接受 1/2；仍校验帧长度、VID、校验和、充电标志和百分比，拒绝 0 与未知状态。本修改没有增加有线接收器 ID，也不把状态值直接等同连接类型。
- 手动标定的报文类型下拉框原先没有写入 ProtocolSpec，测试还根据 Feature 长度覆盖选择。现测试和保存均使用选定 mode；后台任务启动前固定接口和参数，避免后台访问 Tk 或切换选择造成错配。旧标定文件缺少 mode 的，需要选择正确类型后重新保存。err=31 还可能有其他设备/驱动原因，不能保证所有此错误均由本缺陷造成。

## 验证及使用

测试使用真实日志的接口与键盘身份、合成状态帧和模拟 HID 收发，不写真实外设设置。测试覆盖手动标定所选 output/feature 的实际调用、保存重载、后台接口固定；迈从状态1/2和损坏回包；A9非线性DPI编码、地址、身份、未改档位保护和读回失败；GT98身份及G4集合筛选。

退出旧监测程序后运行本构建。ATK若仍无法读配置，唤醒鼠标、关闭占用接收器的配置软件后重读；新的诊断工具会记录匹配身份后的PAW3955专用DPI采集。没有有效回复时不会填入默认DPI。
