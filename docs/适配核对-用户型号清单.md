# 用户型号核对与本次适配（2026-10-27）

主程序仍为 v1.0.2，诊断工具仍为 v1.5.0。最新构建 `20261027-wireless-battery` 的新增范围见《适配说明-无线电量扩展.md》；本页保留此前用户指定型号的核对结果，这些型号不会因加入其他品牌协议而被算作已适配。
下表区分已实现读取通道、依赖系统上报、协议仍待确认；不把显示名称、官方驱动支持列表或接口枚举当作实机验证。

## 本次实际改动
- 已按用户要求移除日志导入及本地绑定；后续按品牌型号逐步补齐内置适配。

- 新增 XInput 电量接口。兼容设备返回“空、低、中、满”四档时，主页和挂件显示档位，托盘悬停显示档位；不换算百分比、不触发百分比低电量预警。有线供电、未知电池类型、断开均单独处理。XInput 仅给出槽位，不能据此确定 Xbox 型号、USB/蓝牙连接方式，也不与蓝牙设备强行合并。
- 蓝牙电量采集不再限于 JBL USB 发射器出现的情况。独立进程记录所有品牌的 Windows 蓝牙设备电量属性、连接状态、缓存标记、匿名设备关联标识；一个采集渠道失败不会取消其他采集。蓝牙系统本身没有电量时，日志明确保留未提供，不猜测百分比。
- 保留诊断 Feature 查询/回复重复记录的修复，便于后续分析完整通信。
- 这些新增通道经过合成报文和系统接口测试；没有对本清单全部实物做过连接测试，也没有执行灯效、DPI、固件或配对写入。

上述 21 个型号中，以下 **13 个缺少对应型号的专用适配**；通用蓝牙电量有可能可用，不计为专用适配完成：

## 已有设备的更多协议验证

已有内置协议包括 XY 键盘、DELUX、AJAZZ、AULA、Weisheng、CompX、页面式电量、MCHOSE、VAXEE、Endgame Gear、WLmouse、Akko/MonsGeek 等，仅在各自已核实的设备和接口上使用。日志绑定模板已移除。
已有 ROG、怒喵、罗技、雷蛇等专用通道继续由各自适配器处理；没有把它们简化为通用任意 ID 绑定。灯效和 DPI 写入仍需型号级协议支持。

## 使用方式

已支持的设备连接并唤醒后，监测程序直接读取电量，无需导入。未支持或读取异常时，连接设备并运行诊断工具，把桌面生成的完整 ZIP 交回分析。确认协议后再更新监测程序内置适配；程序不再提供日志导入或自动绑定。
