## 已核对的查询依据与接入条件

- 官方 JM 驱动通过 Report ID 08、16 字节报告体传输；Windows 完整报告为 17 字节。电量查询命令为 04，电量在含报告 ID 的偏移 6，官方最大值为 100。
- 在线查询命令 03；身份查询命令 01，可取得 CID/MID。必须结合接收器 ID、FF02:0002 集合及报告长度匹配；不能仅凭达尔优 VID 发送命令。
- 同一个 1114 接收器可配 A950 PRO、PRO Mg、A950G，不能继续依赖接收器 ID 独断商品型号。进一步接入时要先读身份，并避免对其他配对型号开放 Mg 专有设置。
- 电量读取的协议线索已较完整；接入时仍需补齐请求/回复校验、未连接状态、充电语义、超时和旧固件差异测试，并用实机验证。未通过验证的回复不得显示成 0%。
- 本轮没有运行官方网页脚本、没有执行固件或安装包、没有向外设发出新命令。下载的官方原文分析后删除，仅保留归纳事实与校验散列。
