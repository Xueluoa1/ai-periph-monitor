# 任务栏图标样式

在 **设置 → 外观 → 任务栏图标样式** 中选择：

- 原有方框（默认，保留原来的外观）
- 底部电量条
- 圆环进度
- 电池轮廓
- 切角铭牌
- 分段电量条

选择后自动保存并立即更新正在运行的任务栏图标，重启后保留。独立显示和合并显示共用这一设置；合并显示所选的常驻设备保持不变。关闭任务栏显示时，样式在下次开启后生效。

选择框下方同时显示浅色、深色任务栏预览，包含正常、蓝牙、低电量、充电和未知状态。预览是示例电量，图标由与任务栏相同的代码按当前 Windows 任务栏尺寸绘制。实际图标配色跟随 Windows 任务栏主题：USB / 2.4G 为绿色、蓝牙为蓝色、电量不超过 10% 为红色、未知为灰色。底部条、圆环、分段条会随电量变化；轮廓和铭牌内显示具体电量。

本次仅增加图标绘制和设置功能，没有新增图像处理依赖，不修改设备硬件设置，也不增加电量查询。诊断工具无需更新。主程序版本保持 v1.0.2。
