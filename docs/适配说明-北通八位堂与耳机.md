# 北通、八位堂与无线耳机电量扩展（2026-10-29）

主程序仍为 **v1.0.2**，诊断工具仍为 **v1.5.0**，构建标识 `20261029-gamepads-headsets`。本次加入 28 个 VID/PID 条目，不等于 28 个独立零售型号。仅加入无线电量读取；已有鼠标、键盘、耳机、手柄适配继续保留。日志导入功能保持移除。

**验证范围：**接口匹配、公开回包样本、合成异常报文、自动查询与日志导出已经纳入回归测试；本项目尚未连接本次新增设备验证。匹配到型号不等于已经收到电量，必须有合法回复才显示读数。固件、工作模式与接口不同可能仍需调整。

## 北通新增 15 个接收器条目

VID 均为 `20BC`；只匹配 `FF00/00FF:0003`、Input/Output 均为 64 字节的厂商集合，使用明文状态查询 `02 15`，解析百分比与已知充电状态。表中按硬件 SKU 命名，不推测“阿修罗”等零售别名。

| 硬件 SKU | 2.4G 接收器 PID |
| --- | --- |
| KP20D / KP20DL | 5159 / 5170 |
| KP40D / KP40MCF / KP40MCK | 515C / 5166 / 5164 |
| KP50C / KP50D / KP50E / KP50B | 514A / 5151 / 5153 / 5134 |
| KP70A / KP70A1 / KP70B | 5130 / 516E / 5160 |
| KP70C / KP70C1 / KP70C2 | 5174 / 518B / 518D |

公开研究中 KP70C2 有 `02 15 5B 00 50 01 00 50…` 的 91% 抓包，其余条目依据型号协议表接入，尚待分别实测。已有鲲鹏20 `20BC:5191` 路线保留。未加入 USB 有线 PID、`20DD` 升级／休眠身份、需要加密的旧型号和 PG01A。不能把所有“鲲鹏”设备都按该命令查询。

## 八位堂蓝牙：被动接收已有电量报告

| 型号 | VID:PID |
| --- | --- |
| SF30 Pro | 2DC8:6000 / 6100 |
| SN30 Pro | 2DC8:6001 / 6101 |
| Pro 2 | 2DC8:6003 / 6006 |
| Pro 3 | 2DC8:6009 |

必须同时匹配蓝牙路径、手柄 Usage 和足够的输入报告长度；同 ID 的 USB 直连接口不启用。已有增强报告中可读取百分比和充电标志。每次最多监听 0.6 秒、16 次读取，不发 Output、不读写 Feature，也不更改手柄工作模式。部分型号需要游戏或其他软件事先启用增强报告，否则显示无有效电量。

SDL 的 Feature 06 “读取”会切换旧型号的输入模式，可能影响 DirectInput，因此本程序不调用它。普通报告补零后的 0 值不能证明电池为 0%，会拒绝该歧义值。Pro 3 公开样本 `04…14` 对应 20%；其他固件和模式仍需对照验证。未将这套蓝牙格式扩展到八位堂全部 2.4G 接收器；Ultimate 2C 等缺少相同电量字段的模式未加入。

## 无线耳机新增 6 个条目

| 型号 | 2.4G 接收器 VID:PID | 电量范围与限制 |
| --- | --- | --- |
| HyperX Cloud Alpha 2 Wireless | 03F0:08BE | 百分比；FF13:FF00，50 02 查询、51 02 回复；充电状态未知。音频接口 0ABE 不套用 |
| 赛睿 Arctis Nova 3P Wireless | 1038:2269 | 百分比、充电状态；复用已核对的 Nova 状态协议 |
| 赛睿 Arctis Nova 3X Wireless | 1038:226D | 同上 |
| 赛睿 Arctis GameBuds | 1038:230A | 当前活动耳塞的最低百分比；入盒耳塞不计入，不读取充电盒电池或推测充电状态 |
| 索尼 INZONE H5 | 054C:0EBF | 百分比、充电状态；FF04:0002、64 字节报告 |
| 索尼 INZONE H9 II | 054C:0FA8 | 百分比、充电状态；FF04:0001、64 字节报告 |

索尼只发送电量 GET；按事务 ID、事件类型、目标地址、长度及校验和筛选回复，忽略旧事务、通知、请求回显及离线 FF。不会修改降噪、音量、麦克风、配对或固件。

## 仍未补齐的部分

- **墨将：**找到 ARMOR-X Pro／战甲 Pro（ZJ-XT）标准蓝牙 Battery Level `2A19` 的实测证据，但目前程序仅读取 Windows 已公开的系统蓝牙电量，尚未新增直接 GATT 读取。不能据此声称其 2.4G、其他墨将型号已适配；USB 私有通道仍缺少可靠电量查询与连接状态定义。
- **北通阿修罗：**已查到阿修罗 2、3S 等身份／说明书，但尚无足够的对应无线电量报文与接口证据，未新增私有查询。Windows/XInput 已上报的系统电量仍可显示。鲲鹏硬件 SKU 不直接改名为阿修罗。
- **更多耳机／星闪手柄：**系统提供蓝牙电量时沿用系统通道；本轮没有新增未经核实的星闪手柄私有命令。JBL Smart Tx、K03S 等此前未确认的电量通道仍待验证。

## 自动查询与诊断

连接并唤醒设备后，监测程序按硬件身份和接口自动读取，不需要先运行诊断。诊断工具共用同一查询与解码代码；八位堂纯输入接口也会被调度，记录收到的报告与解析结果，不触发通用 Feature 扫描。其他新增通道记录查询、原始回复与失败原因。没有回包时不会填入假电量。

需要验证新硬件时，运行随包诊断工具并提供桌面 ZIP，同时记录当时官方软件显示的电量、连接方式、充电状态。新协议无需逐个手动选择。
