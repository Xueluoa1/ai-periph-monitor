# 无线外设电量监视器 v1.0.2

最新构建 `20261111-tray-styles`：新增 5 种任务栏图标样式：底部电量条、圆环进度、电池轮廓、切角铭牌、分段电量条，保留原有方框为默认。浅色/深色实时预览，切换立即生效并保存，适用于独立与合并显示。修复点击左侧导航后侧栏出现黑色外框的问题。详见[操作说明](使用说明-任务栏图标样式.md)。诊断工具无需更换，本次不改变型号适配范围。

此前构建 `20261111-compact-centered-hover`：任务栏支持合并显示、选择常驻设备与悬停查看全部已选设备；面板紧凑并居中对齐图标，屏幕边缘避让。支持滚动、保存/取消与断连保留选择，不增加硬件查询。详见[使用说明](使用说明-任务栏合并显示.md)。诊断工具无需更换；[达尔优核对报告](达尔优适配核对-20261111.md)仅为研究，未新增型号支持。

此前构建 `20261103-rog-harpe2-pelta`（版本号不变）：依据 fa0303ce 日志确认的接口，新增龙鳞 ACE 2 / SPEEDNOVA 8K（0B05:1AD0）及破风 PELTA 耳机（0B05:1B84）的专用电量查询。耳机使用 CC 报告，百分比与鼠标偏移不同，充电状态另行查询；鼠标空键盘槽和耳机其他集合不套用查询。主程序与诊断工具共用协议。原日志未包含有效电量回包，本次已实现读取，等待实际电量回复验证。详见《适配说明-龙鳞ACE2与破风耳机.md》。

此前构建 `20261030-discovery-consistency`（版本号不变）：修复主页遗漏标准 Input 电量接口，以及同一 Usage Page 的首个接口失败后跳过其他集合的问题。自动读取与内置调试器均可在已声明标准电量字段的接口等待最多 3 秒，收到有效值立即结束；没有电量字段的普通输入不会被监听。专用型号仍仅走已核实协议。成功的标准电量通道可替换同一设备的失败卡片，保留原显示键以继续遵守隐藏／命名设置。修复内置调试器漏掉后续成功查询、蓝牙 0% 被显示为未知、电量档位被误写为电压模式，以及主页电量数量未计入档位的问题。未确认的私有协议和没有回复的设备仍显示未知，不保证所有调试器可枚举设备都有电量。独立诊断工具本次无需更换。

此前构建 `20261029-gamepads-headsets`：新增 15 个北通鲲鹏系列接收器 SKU、7 个八位堂蓝牙硬件 ID，以及 HyperX Cloud Alpha 2、赛睿 Nova 3P／3X／GameBuds、索尼 INZONE H5／H9 II 的 6 个 2.4G 条目。八位堂仅被动读取已有增强报告，不切换手柄模式；普通报告缺少电量时仍显示未知。新增均待本项目实机验证。墨将私有通道、北通阿修罗仍未接入；不扩大声称为全品牌支持。诊断工具同步更新，详见《适配说明-北通八位堂与耳机.md》。

此前构建 `20261029-wireless-controllers`：加入北通鲲鹏20、飞智八爪鱼5／黑武士5 Pro、小鸡旋风2的无线电量协议，以及赛睿 Aerox 3／5／9、Prime／Prime Mini 的指定 2.4G 版本，共新增 13 个硬件 ID。飞智显示真实档位，赛睿标注约值；诊断工具同步自动查询。此次新增均待本项目实机验证，不代表支持这些品牌全部型号。星闪保留已确认通道，没有加入未知星闪手柄命令。详见《适配说明-无线手柄与鼠标.md》。

- 诊断工具：导出所有可打开接口的 Windows HID 解析能力表和集合树，增加物理设备分组；严格筛选厂商接口进行短时被动采样，自动复用更多已收录型号的电量查询，区分无协议、无回复、未解析和失败状态。

- 393 项回归测试通过，打包检查及本机诊断试运行通过；无法打开的接口保留失败信息。

小米设置页提供档位颜色选择器。回报率选项随设备当前性能模式限制，最高 8000 Hz；需要提高性能模式时请使用官方驱动后重读。本版不自动更改性能模式，不提供无协议依据的 RGB 动态灯效或亮度滑条。

小米原日志只有接口信息及通用 Feature 快照，无法读出实际电量和 DPI。诊断工具 v1.5 新增了它的专用只读查询，入口仍为 `多品牌外设诊断工具.exe`。请使用新版采集一次小米日志，以便核对实机响应；无需改变鼠标设置。

每次设置均先核对当前配置，写后读回确认；失败不自动重发。独立 X/Y DPI 开启时保留数值，提示用官方驱动调整；颜色和档位切换仍可用。

RK 共享接收器名称属于用户确认的关联，不能仅凭此 ID 识别所有用户的键盘型号。也修正了诊断器将 PixArt 触控板标成因科特鼠标的品牌标签。

具体协议来源、限制及实机验证边界见 `适配说明-v1.0.2.md`，测试与文件校验见 `release-manifest-v1.0.2.json`。旧安装不自动替换，开机启动不更改。
