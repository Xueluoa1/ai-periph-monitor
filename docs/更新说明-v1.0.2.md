## 2026-10-26 同版本更新

本次构建标识为 `20261026-comprehensive`，主程序与诊断工具版本号均不变。

- 达摩鲨 M3 Pro：新增 1915:0723 接收器的只读电量查询，先核验配对型号再读电量；依据官方驱动静态分析，等待实机回复验证。
- 诊断工具：导出所有可打开接口的 Windows HID 解析能力表和集合树，增加物理设备分组；严格筛选厂商接口进行短时被动采样，自动复用更多已收录型号的电量查询，区分无协议、无回复、未解析和失败状态。
- 西伯利亚 K03S：日志设备与官方旧音频驱动包的硬件 ID 不同，电量协议仍未确认；此次补充采集，不显示未经验证的电量。
- 393 项回归测试通过，打包检查及本机诊断试运行通过；无法打开的接口保留失败信息。

详见包内 `适配说明-首次完整采集.md`。以下为此前 v1.0.2 的更新内容。

| 设备 | 本版状态 |

| VXE 蜻蜓 R1 星闪版 | 已确认与原 R1 NK 适配相同；修正名称，保留电量、DPI、回报率及只读档位颜色 |
| RK-G98 | 根据用户确认显示名称；2.4G 电量、灯效仍未适配，不套用不同接口的有线协议 |

小米设置页提供档位颜色选择器。回报率选项随设备当前性能模式限制，最高 8000 Hz；需要提高性能模式时请使用官方驱动后重读。本版不自动更改性能模式，不提供无协议依据的 RGB 动态灯效或亮度滑条。

小米原日志只有接口信息及通用 Feature 快照，无法读出实际电量和 DPI。诊断工具 v1.5 新增了它的专用只读查询，入口仍为 `多品牌外设诊断工具.exe`。请使用新版采集一次小米日志，以便核对实机响应；无需改变鼠标设置。

每次设置均先核对当前配置，写后读回确认；失败不自动重发。独立 X/Y DPI 开启时保留数值，提示用官方驱动调整；颜色和档位切换仍可用。

RK 共享接收器名称属于用户确认的关联，不能仅凭此 ID 识别所有用户的键盘型号。也修正了诊断器将 PixArt 触控板标成因科特鼠标的品牌标签。

具体协议来源、限制及实机验证边界见 `适配说明-v1.0.2.md`，测试与文件校验见 `release-manifest-v1.0.2.json`。旧安装不自动替换，开机启动不更改。
