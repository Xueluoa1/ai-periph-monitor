# 2026-10-26 同版本更新：首次采集与达摩鲨 M3 Pro

主程序仍为 v1.0.2，诊断工具仍为 v1.5.0，以构建标识 `20261026-comprehensive` 区分此次文件。未部署、未修改自启动。

## 首次采集改进

- 所有可打开 HID 接口导出 Windows HidP 解析的能力表：Input/Output/Feature 的值与按钮字段、完整 Usage 范围、Report ID、位宽、数量、逻辑与物理范围、单位、数据索引及集合树。
- 普通键盘/鼠标接口只读描述资料，不监听按键或移动。只有顶层厂商接口且所有输入字段均为厂商定义时，才执行最多 1.5 秒、32 帧/8 个不同报文的被动采样。它不发送命令，不把任意字节当作电量。
- 接口清单增加匿名物理设备分组标识、接口编号与集合编号。同一接收器的多个集合不代表多个实体设备。
- 自动复用监测工具的型号与接口严格匹配的电量协议，包括原先未接入诊断的 Akko、AULA、Rapoo、DAREU、AJAZZ、HECATE、Lofree、RK、VAXEE、Endgame 等相应已收录型号。不是这些品牌所有设备的通用协议。
- 逐接口显示未收录协议、查询无回复、原始回复未解析、电量候选或超时。保留部分结果，不用“未确认”掩盖不同原因。
- Windows 用户态 HidP 返回的是解析结果，未取得原始 USB Report Descriptor 字节时明确标注，不把解析表或 Physical Descriptor 冒充原始报告描述符。设备权限、休眠和总时限仍可能使采集不完整。

## M3 Pro 协议依据

用户日志 e9f940ea：1915:0723，MOJI / 1K NRF Receiver，FF0A:0001，Input/Output 65，Feature 0。

静态分析 [官方 M3 Pro 驱动下载页](https://www.darmosharkgear.com/de/article_1/39.html) 提供的 Beta 1.6.7.11 包，未执行安装器、驱动或固件升级器。配置文件将 1915:0723 MI03 同时列给 M3 Pro 和 M3S Pro，故必须核对返回的配对型号。

用于审计的事实（偏移均针对该二进制，不适用于其他版本）：

- DeviceDriver.exe SHA256：`1ac32bc7ddf1f3854a4f35a2c318ea19ed609d082af1dad727ac8144ddb8a220`。
- `GetNodic24DeviceStatus` VA 0x4517B2：读取状态的 64 字节命令体起始 `01 00 81 01`。回复体 command=0x8C，body[4] bit3 是连接位，body[11:13] 小端型号 0x0711 对应 M3 Pro，0x0710 对应 M3S Pro。
- `GetNodicMouseData` VA 0x432F43：无线鼠标状态查询体 `41 00 81 01`。回复体 body[5] 为充电状态、body[6] 为电量；与 `DUI.dll!SetBatteryInfo` 的百分比/充电参数顺序交叉检查。
- `0x451640/0x451920` 的发送封装在体前加 Report ID 0，体最后字节补足 sum(body) mod 256 = 0xA1。接收器/鼠标查询校验分别 0x1E/0xDE。`0x4526B0` 接收封装去除前置零 Report ID。
- 独立实现仅两种 GET 状态帧，不实现设置、升级或配对。未知型号、离线、命令不匹配、异常充电码或百分比不会展示成有效电量。零电量正常保留。

已接入监测程序和诊断工具；协议来自静态分析及合成回复测试，尚未获得这台 M3 Pro 的实际状态回复，不声称实机验证完成。

日志确认 10D6:4801，产品字符串 XIBERIA K03S，FF90/RID55 与 FF82/RID41 厂商接口。旧日志没有电量回复。
目前未确认适用于该接口的电量命令和解码规则，不套用其他 Actions 芯片耳机的指令。此次诊断可采集符合条件的主动上报，仍不保证设备主动发送电量。

另静态检查了[西伯利亚官方下载页](https://www.xiberia.net/h-col-172.html)的 K03S 无线 7.1 驱动 `USB Gaming Headset_Setup_1.0.4.exe`，安装包 SHA256 为 `871c2d1794dfafd04a1f8246a2b3e9cf375686809b27bad3efa4e79f218b43a2`。其中音频驱动与扩展 INF 匹配的是 `36F9:C001 MI01`，与日志的 `10D6:4801` 不同；静态检查未获得适用于日志设备的电量查询依据。这不证明设备没有电量功能，只说明该下载包不足以确认协议。未运行厂家安装器或程序，研究用下载与解包文件在分析完成后删除。
