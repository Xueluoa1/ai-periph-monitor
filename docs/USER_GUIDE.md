# 软件操作手册

适用：主程序 v1.0.2，构建 `20261029-gamepads-headsets`；Windows 10/11 x64。

[返回首页](../README.md) · [品牌型号适配](SUPPORT.md) · [作者声明](../AUTHOR_STATEMENT.md)

## 1. 下载、启动与退出

1. 从 [Releases](https://github.com/Xueluoa1/ai-periph-monitor/releases) 下载主程序便携 ZIP，解压到一个固定文件夹。
2. 双击 `无线外设电量监视器-v1.0.2.exe`，无需另装 Python。不要直接从压缩软件预览窗口运行。
3. 插入 2.4G 接收器并唤醒设备；蓝牙设备先在 Windows 中完成配对和连接。
4. 打开「设备」页，点击「立即刷新」。默认刷新间隔为 1 分钟。
5. 彻底关闭请使用「设备」页底部的「退出程序」；仅关闭窗口不应作为退出后台监测的操作。

「设置 → 高级与维护 → 安装与快捷方式 → 一键安装到 Windows」是可选安装入口；便携运行不需要先安装。「开机启动」可在设置中单独开关，切换前查看当前状态。

主界面四个入口是「设备」「外设设置」「设备测试」「设置」。

## 2. 查看电量和管理设备

- 「设备」页显示当前读取值及状态。显示不可用、未连接、休眠或缓存时，应同时阅读状态文字；缓存值不是刚刚测到的电量。
- 点击「立即刷新」重新查询。部分 2.4G 设备休眠后不回复，先移动鼠标或唤醒键盘再刷新。
- 「管理设备」可以修改自定义名称、取消某台设备的「显示」，然后点击「保存」；留空名称恢复自动识别。「全部恢复显示」后仍需保存。
- 全局隐藏同时影响设备页、任务栏、挂件和低电量提醒。仅想减少任务栏/挂件图标，请使用下方各自的设备选择，不要全局隐藏。
- 「设置 → 常规」可调整自动刷新与间隔：30 秒、1/2/5/10/30 分钟。该开关的界面含义是主界面自动刷新；后台是否继续运行请查看托盘与后台进程状态。

### 新增手柄、鼠标与耳机通道

本构建包含[无线手柄与鼠标](适配说明-无线手柄与鼠标.md)、[北通、八位堂与耳机](适配说明-北通八位堂与耳机.md)两批适配。连接表中指定接收器或蓝牙模式并唤醒设备后点击「立即刷新」，无需运行诊断或导入日志。新增设备均待本项目实机验证，具体 VID/PID、模式和接口以两份说明为准。

飞智显示原始 0–5 档，不转换为百分比；赛睿新增无线鼠标显示以 5% 为单位的约值。八位堂仅被动监听已有增强报告，不切换工作模式；若系统当前只有普通报告，可能仍无法获取电量。GameBuds 显示当前活动耳塞的最低电量，不提供充电盒读数。未收到合法报告时不会填入假电量。本次不新增按键映射、振动、灯效、配对或固件设置。

### 新增无线接收器电量

连接支持表中的接收器并唤醒外设，然后点击「立即刷新」即可查询，无需先运行诊断或导入日志。本次涵盖六个品牌、57 个接收器 ID，具体型号和接口见[无线电量扩展说明](适配说明-无线电量扩展.md)，新增硬件均待实机验证。

赛睿部分旧固件仅提供原始电量档位，界面显示“2/4 档”等，不换算百分比，也不触发百分比低电量提醒。无回复、休眠、错误报文不会显示为 0%；实际收到有效 0% 时仍正常显示。充电状态只在协议提供有效字段时显示。本次只扩展电量，不增加这些型号的 DPI、灯效、配对或固件操作。

### 蓝牙电量

本版读取 Windows 可提供的电量属性，并合并同一物理设备的服务节点。主要适用于提供相应属性的蓝牙耳机等设备，不保证每个蓝牙键盘、鼠标或音频设备都上报。

设备已连接但没有电量属性时仍可能出现在列表中，电量显示不可用；系统缓存会按状态标注。刷新软件不能强迫设备立即向 Windows 上报。蓝牙电量能读到不代表能用本工具设置该设备 DPI。

### XInput 手柄电量

让手柄保持连接并处于 Windows 能识别的 XInput 模式，随后点击「立即刷新」。系统提供有效电池档位时，设备页和桌面挂件显示“空、低、中、满”，任务栏图标悬停可查看档位。档位不换算为百分比，也不触发百分比低电量通知；有线供电、未知电池类型和断开状态分别处理。

XInput 最多提供四个槽位，不能据此识别具体 Xbox 型号或判断 USB/蓝牙连接方式，也不会与蓝牙记录强行合并。断开、接口失败或槽位重新分配后会清除旧档位。是否能够读取取决于系统和设备，详见[用户型号核对表](适配核对-用户型号清单.md)。

## 3. 2.4G 鼠标 DPI 与外设设置

1. 进入「外设设置」，连接接收器或受支持的数据线，唤醒设备。
2. 点击「重新读取设备」，在列表选择正确设备。部分通道需再点「读取 DPI 档位」。
3. 在某个档位旁点「修改」，输入范围和步进允许的整数 DPI，点「确认修改」。成功以设备读回结果为准。
4. 若通道支持软件切档，选择档位后点击「应用」。不支持切档的型号请用鼠标本身的档位键；修改数值和切换当前档位是不同操作。
5. 支持的型号可点「读取回报率与灯光」，读取后再选择参数并点对应的应用按钮。

页面只显示该通道支持的选项。设备断开、身份不符、配置过期或读回失败时，先重新读取并核对设备，失败不等于设置成功。不同 X/Y DPI 的处理随协议而异，请遵循页面提示；不确定时用官方驱动调整。

部分“颜色”控制实际是 DPI 档位指示色，不是机身 RGB 动态灯效。8000 Hz 等选项依赖接收器、固件及性能模式，不会仅因型号名称而开放。未知设备、蓝牙连接或未匹配的共享接收器不会通用猜测写入。

## 4. 键盘、鼠标按键及回报率测试

1. 进入「设备测试」，点击「开始测试」，保持测试页在前台。
2. 持续移动鼠标，查看 Hz 数值；它统计最近 1 秒收到的移动报告，按设备分别统计。
3. 点击左/中/右键、侧键 1/2，查看状态和次数；滚动滚轮观察累计值。
4. 按键盘按键，观察键位高亮、已测键位和同时按键峰值。
5. 点击「停止测试」结束；切换页面会停止，窗口不在前台时暂停采集。再次开始会清空统计。

**这里的 Hz 是 Windows 实际收到的鼠标输入频率，不等于固件设置的回报率，也不是精确延迟测试。** 鼠标静止、移动速度、系统负载和输入处理均可能影响读数。键盘部分做按键检测，本版不提供键盘硬件回报率测量。Fn 等不向系统上报的按键无法检测。

测试不保存输入内容；不要把它作为硬件实验室级测量结果。

## 5. 桌面挂件

「设备」页可开关「桌面挂件」，点击「挂件设备」选择自动显示全部，或取消自动后手动勾选设备并保存。

「设置 → 桌面挂件」包括：

| 选项 | 操作与效果 |
| --- | --- |
| 显示桌面挂件 | 开关挂件显示 |
| 紧凑模式 | 在完整卡片与紧凑模式之间切换 |
| 挂件尺寸 / 分辨率 | 选预设或自定义宽高；自定义后点「应用尺寸」；过大时限制在屏幕范围内，内容过多可滚动 |
| 锁定位置 | 需要移动时先解锁，拖动到合适位置后再锁定 |
| 显示位置 | 「固定在桌面底层」或「始终置顶悬浮」 |
| 不透明度 | 100%、92%、80%、65%；数值越小越透明 |

挂件和任务栏的设备选择相互独立。保存了空选择就不会显示任何设备，新增设备是否自动加入取决于「自动显示全部」是否开启。

## 6. 任务栏电量显示

- 打开「显示到任务栏」，在 Windows 通知区域查看设备电量数字图标。
- 点击「任务栏设备」，选择自动全部或手动勾选并保存。
- 关闭任务栏显示只隐藏图标，后台监测继续；想停止后台请使用「退出程序」或设置中的后台退出入口。
- 图标不在主任务栏时先展开 Windows 通知区域的隐藏图标。悬停查看设备状态，右键菜单操作以当前菜单文字为准。

## 7. 低电量通知

进入「设置 → 低电量提醒」，打开「启用提醒」，选择阈值，再点击「测试通知」确认弹窗显示。

可选阈值是 10%、15%、20%、30%、50% 和用于测试的 95%；默认 20%。日常使用建议将 95% 改回实际需要的低电量阈值。提醒依赖后台运行和有效电量数据；全局隐藏的设备不会提醒。不要把测试通知出现理解为所有设备电量协议都可用。

## 8. 浅色 / 暗色主题

在「设置 → 外观 → 界面主题」选择「浅色」或「暗色」，即时应用并保存，下次启动沿用。设置会通知后台刷新相关界面。

## 9. 配置、更新与常见问题

配置主要保存在 `%LOCALAPPDATA%\Programs\DeviceBatteryViewer\tray_config.json`。退出程序后备份该文件可保留个人设置；不要将个人配置上传到公开仓库。

更新时先退出旧程序，再解压新版到固定目录运行。若使用安装或开机启动功能，检查对应入口指向的新路径；此发布包不会自动替你更换正在运行的版本。相同 v1.0.2 版本号可能对应不同历史构建，请核对 `20261029-gamepads-headsets` 和 SHA256。

| 问题 | 排查办法 |
| --- | --- |
| 没发现设备 | 检查连接方式、接收器、供电，唤醒设备后立即刷新 |
| 能看到名称但无电量 | 看状态文字与适配表；设备名称识别不代表协议支持 |
| 蓝牙显示旧值 | 核对是否标为系统缓存；等待设备再次上报，确认 Windows 连接状态 |
| DPI/灯光入口不可用 | 核对精确型号、USB ID、接口及固件；有电量不代表有配置通道 |
| 读取失败或接口被占用 | 自行退出对应官方驱动后重试；软件不会替你终止厂商进程 |
| Hz 低于设置值 | 持续移动鼠标并检查连接模式、负载；它测量实际输入事件而非硬件规格 |
| 挂件/托盘不显示 | 检查总开关、各自设备选择、全局隐藏状态和后台进程 |
| 关闭窗口后仍在运行 | 使用「退出程序」完整退出，或在设置中退出托盘与挂件 |

## 10. 诊断与反馈

仅在需要排查或适配设备时下载诊断工具 v1.5。解压运行，保持设备连接和唤醒；一般数十秒，接口超时时可能约 3 分钟。日志写到 Windows 桌面，无法写入时回退临时目录，实际位置会在窗口显示。

诊断器采集接口、能力表、严格匹配通道的查询与响应，不修改设备配置；它不是所有品牌的万能驱动。「协议调试器」是另一个面向开发者的高级工具，包含手动报文操作，不建议普通用户随意使用。

反馈请说明：准确品牌型号、连接方式、VID/PID、固件、软件版本/构建标识、复现步骤、期望与实际结果。原始日志可能含设备标识，公开 Issue 前请检查和脱敏；不要直接上传整份私人日志。本工具不自动上传日志。


本构建增加独立的 Windows 蓝牙与 XInput 系统采集，记录 `system_battery.jsonl`，并汇总到诊断 JSON 和摘要。蓝牙采集不再以 JBL 发射器出现为前提，系统未提供电量时明确记录缺失；系统采集失败不取消其他通道。当前版本不提供日志导入和本地协议绑定。

完整诊断说明见 [使用说明与适配指南](../tools/peripheral_diagnostic/使用说明与适配指南.md)。作者后续更新随缘，不承诺响应时限。
