# M618XSD 与开关边缘修复

构建 `20261026-m618xsd-antialias`。监测程序保持 v1.0.2，诊断工具保持 v1.5.0。

## 本次日志

批量压缩包中有一份 `092fd3ca` 诊断日志和一张设置开关截图。用户确认鼠标为多彩 DELUX M618XSD。

- `320F:221D` / Wireless Gaming Mouse；厂商控制集合 `FF1C:0092`，Input、Output 64 字节，Report ID 4，Feature 0。
- 同一设备的普通鼠标、键盘快捷键和媒体集合不是额外的实体键盘。辅助 RID5 集合不用于电量查询。
- 原日志仅有描述符和 1.5 秒无主动上报记录，没有电量百分比、DPI 或灯光配置回包。没有发现 JBL Smart Tx 或小鸡 G7 Pro。
- 其他通用接收器、触控板和音频设备保持原有识别；不会因为同时出现在日志中而被命名为 M618XSD。

## 实现

监测程序与诊断工具共用型号专用的在线与电量查询：先发送命令 AA，确认在线标志 FF；再发送命令 1A 读取 6 字节电池信息。百分比位于完整 HID 报文的字节 8；字节 9 的 1/2 分别表示充电/电池供电，0 的外接电源图标仅显示为未知充电状态。过滤错误接口、错误命令、长度、错误状态、超范围数值、回显和超时，不将未连接显示为 0%。

**已实现电量查询和解码，但尚未收到该鼠标实机回包验证。** 本次无需先重新交日志才能启用查询，运行更新后的监测程序即可尝试。诊断工具也会在识别接收器时自动查询并记录响应。DPI、回报率、灯效的配置结构和写入尚未针对该硬件验证，本次不开放这些设置。

依据：[DELUX 官方型号下载页](https://www.deluxworld.com/en-service.html?title=M618XSD)中的 [Version 1.0 驱动](https://www.deluxworld.com/uploads/admin/file/20220209/M618XSD.zip)。静态分析确认其设备表包含 320F:221D 和 FF1C:0092。新版驱动另有协议，未套用。安装程序、升级程序均未执行；临时下载与解包文件分析后删除。独立实现，不随程序分发厂商驱动。

## 开关修复

截图中的“电量提醒”“开机启动”等共用开关改为 4× 超采样绘制，按当前 DPI 和背景色合成边缘，减少圆角与白色滑块锯齿。保留点击、空格、回车、焦点提示和现有配色。缓存小尺寸图像，不引入 Pillow、浏览器或其他运行时依赖。

验证覆盖模拟在线/离线/错误报文、两条查询顺序、诊断自动路由、浅深色主题、100%/125%/150%/200% 绘制、Tk 图像与变量绑定及销毁。模拟报文不是用户实际电量。
