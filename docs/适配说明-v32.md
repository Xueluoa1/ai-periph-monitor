# v32 回报率与灯光扩展

本版承接 v31 的电量、DPI、设备列表编辑、托盘菜单和桌面挂件功能，增加独立 DPI 通道的回报率与灯光。精确硬件 ID、型号、接口与功能范围见随包《v32-品牌型号功能支持清单.md》。新增软件路径不等于每款设备已实机验证，也不覆盖同品牌的所有产品。

## 使用

双击 v32 EXE，打开「鼠标设置」，选择设备，点击「读取回报率与灯光」。界面显示设备当前保存的配置。调整后点击「应用回报率」或「应用此灯区」。颜色用颜色选择器；连续亮度用滑动条；只有几档亮度的设备显示实际档位。

新增 ROG 通道按型号显示 Logo、滚轮、底部灯区。VXE、RK、HECATE、WLmouse 的 DPI 指示颜色明确标为指示灯，不宣称是机身 RGB。Pulsar 显示接收器开关和三组颜色。Endgame v2 的开关只控制抬起鼠标时的指示灯。

罗技通过 HID++ 功能与灯效能力表动态识别。8060/8061 回报率只提供有效上报的档位；8070/8071 只提供实际上报且已实现的常亮、关闭、呼吸和循环。部分8070与全部本版8071通道只能设置，界面保持「当前未知」，不会把选择值或应答当成实际读回。接管8071软件灯效使用已知SWControl命令；不自动切换板载配置模式，不修改板载档位表。

灯光配置读取不能采样循环动画每一瞬间的发光颜色。循环模式没有固定RGB，不以默认颜色冒充当前颜色。可读回通道的模式、颜色和其他配置不一致时报告失败；只写通道明确报告设备接受命令但未读回。

## 新增范围

- 25个已核对 ROG/ASUS 型号/连接 PID：125–1000 Hz；Chakram X、Spatha X从250 Hz起。未根据Booster推测高回报率。TUF M4只加回报率；其余按型号灯区增加基本模式/RGB/亮度。多灯区全局彩虹、彗星未开放。
- Logitech、VXE R1 Pro Max、LAMZU Atlantis协议系列、Scyrox V8、Pulsar指定report-8接口、MCHOSE A5第一代、WLmouse Beast X 4K、Endgame OP1w/XM2w 4K及v2、AJAZZ NJ系列、RK M3、HECATE G3M Pro：按具体协议和连接开放回报率。
- VXE 指示灯常亮/呼吸/关闭，亮度与速度各三档，档位RGB；呼吸模式必须保留旧亮度。关闭状态未保存亮度时显示空白，不伪造中档值。
- RK当前档、HECATE/WLmouse已读取档位的指示RGB；Pulsar只在dongleType=0/3时开放接收器灯光；Endgame v2开放抬起指示灯开关。
- 原有怒喵.97、Harpe Aim Lab、ATK，以及118个控制标识中的现有回报率/灯光适配保留。

AJAZZ虽然能识别250 Hz编码，已核对的写入选项只提供125/500/1000 Hz。WLmouse高性能模式不自动关闭；Endgame玻璃模式不自动关闭；不通过改变这些模式强行开启更高回报率。

Scyrox灯效的有效模式/范围、其他鼠标共享接收器、旧怒喵/旧迈从、Rapoo/Delux未核实设置接口，以及键盘灯效/回报率仍不开放猜测写入。M68HE日志无有效配置，不能仅凭设备名称推断协议。

## 事务与验证

每次写入前重新读取DPI和控制快照，核对设备身份、配置层、档位、灯区和相关原始字段；发生变化就要求重新读取。只修改请求字段，保留相邻记录、保留位、DPI、其他灯区及板载模式。使用已有跨进程锁。写入后重新读取完整快照，不以ACK代替实际读回；罗技仅写通道除外，但仍核对其余可读配置，并明确说明读回限制。写入失败或超时不自动重试，提示可能部分生效。

可选灯光读取失败不隐藏有效回报率；无有效配置时不使用默认值补齐。连接断开、未知编码、错误校验、未知身份、接收器能力不足都不会开放对应写入。

新增30项协议/事务模拟测试与3项隐藏Tk界面测试，结合原195项回归共228项。覆盖型号范围、报文字节、配置保存、会话关闭、身份/快照过期、超时不重试、读回不符、只写灯效保持未知、界面忙碌状态及无隐式写入。**测试不修改真实设备设置；尚未逐型号实机写入验证。**

打包后检查新模块与源码一致、Tcl/Tk与字体完整、EXE只读设备自检，并记录SHA256与真实文件体积。结果见release-manifest-v32.json。
