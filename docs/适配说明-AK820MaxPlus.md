# 黑爵 AK820 Max Plus 电量适配

构建 `20261027-ak820maxplus`；主程序 v1.0.2、诊断工具 v1.5.0 保持不变。

## 日志与识别

日志 `73275d99` 中的 2.4 Wireless Device 为 `1A2C:8FFF`。用户确认为黑爵 AK820 Max Plus。主控制接口为 FF02:0002，Input/Output 65 字节、Feature 0、Report ID 0。普通键盘、媒体、鼠标集合不额外显示为外设；FF01:FF01 的 4 字节输入集合也不是电量查询通道。

该 VID/PID 是 XY 接收器共用 ID，不能唯一证明任意接收器配对的键盘型号，因此名称保留“AK820 Max Plus / XY 2.4G 键盘”。本次不扩大匹配到其他黑爵系列、其他 VID/PID 或有线型号。

日志中另有 INSTANT USB GAMING MOUSE（30FA:1701）和 MyDIYKB ByAmos（5A5A:2023）；未将这些设备当作 AK820 Max Plus。日志没有键盘电量或灯光响应，无法从已有数据给出实际百分比。

## 已加入

核对 AK820 Max Plus 三模 RGB XY 驱动 1.0.4.6 的配置表及静态代码，独立实现电量查询。驱动配置包含 1A2C:8FFF，代码选择 FF02:0002；请求完整 HID 报文以 `00 AA 55 CC 33 0E` 开头，补零至 65 字节。

响应校验长度、报告 ID、头部、命令、连接模式及百分比范围。完整报文第 6 字节（从零开始）为百分比，第 7 字节的 1/3 为驱动接受的连接模式。0 为未连接，不产生 0% 读数；有效在线的 0% 仍可显示。连接模式不作为充电标志使用。

监测程序与诊断工具共用实现，自动执行一次有超时的电量查询，不发送配对、复位、固件、灯光或键位写入命令。未收到有效响应时保留未知电量。

**当前为已实现、待实机验证。** 原日志只能验证接口，测试中的 73% 是模拟值。双击更新后的主程序即可尝试读取，不需要先重新交日志才能开启查询。若未读到，运行同步更新的诊断工具，回包会自动记入日志。
