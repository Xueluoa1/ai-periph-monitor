# v33 K1 适配范围与协议依据

在 v32 基础上新增 `gravastar_k1.py`、`ui_k1_controls.py`，并接入电量发现、外设设置页面。其他品牌范围见 v32 适配说明与 v33 支持清单。K1 仅 2.4G；有线、蓝牙、Pro/Lite 不因此获得设置支持。

来源为 [官方 K1 系列 v3.2 驱动](https://cdn.shopify.com/s/files/1/0295/5988/1807/files/GravaStar_Mechanical_Setup_v3.2_20260113_1.exe?v=1769568388)，安装包 SHA256 `b0b0d3832b8247bab9771bf249cfa755eff34c39d48cc840671dd8ac8a545699`。未运行厂商程序。静态函数证据见随包《GravaStar-K1-协议静态分析.md》；独立实现 Python 通信与数据验证。

## 读取

精确 VID/PID 3554:FA09，Usage FF02:0002，输入输出各20字节；通过 HID 能力表核对输入与输出报告 ID 13。命令07确认在线，05确认6字节签名。仅标准版/DE/JP的已知签名可继续。电量4A返回2字节；灯光44返回128字节并验证5AA5尾标记；颜色49请求420字节。

接收端检查报告ID、命令、长度、加和校验、错误标志、包数、包序号和重复包一致性；乱序分包重组后必须满足完整长度。未知格式不补默认值。电量全零数据保守视作无效；有有效状态字节时允许报告0%。

## 写入

灯光04按14字节负载分包；颜色09同样分包。每包确认应答，写入不自动重试。先重读快照核对型号与完整配置；只改目标效果编号、选定效果的亮度/速度参数，以及可选的第一个调色板颜色。保留所有未修改字节。写完核对完整灯光配置、颜色表与型号，任何差异都不报成功。

内置效果编号1–18；硬件21为自定义逐键效果，只保留和识别，不提供逐键编辑。本版以设备编号命名效果，避免把驱动内部效果编号误译成其他效果。亮度/速度原生值0–4；第一内置效果不提供速度滑动条。颜色仅在官方配置允许该效果颜色编辑、低半字节颜色标志为0且完整颜色表可读时开放；否则保留原颜色。

## 颜色布局补充证据

官方0x49CD30起按灯效硬件编号乘21定位调色板，每组7个RGB，各3字节；RGBIndex=0,1,2。0x49CF3E向SetLedRgbTab传入420字节。官方低层0x4946D0使用写入命令09，0x494710提供读取49。实现只修改选中效果调色板的第1个RGB（硬件编号×21），不重建整张颜色表，不把无效颜色表当作全黑。

257项回归测试通过，包括25项K1协议/事务/路由测试与4项隐藏Tk测试。覆盖错误接口/报告ID/型号、分包乱序/重复/丢失/校验错误、电量空值、配置过期、保持其他配置、写入失败不重试、部分颜色失败不继续写配置、读回失败不报成功、UI不隐式写入、忙碌状态和K1专用页面入口。
