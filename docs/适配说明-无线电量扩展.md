# 无线电量扩展（2026-10-27）

主程序 v1.0.2，诊断工具 v1.5.0，构建 `20261027-wireless-battery`。版本号不变。

本次面向 2.4G、蓝牙及星闪。新增条目全部是无线接收器 ID，不加入 USB 有线直连 ID。USB 接收器仍是 2.4G/星闪设备与电脑之间的通信入口。

## 蓝牙、星闪与原有适配

- 蓝牙：沿用无品牌白名单限制的 Windows 电量属性读取，涵盖系统实际上报电量的鼠标、键盘、耳机、音箱及手柄。没有上报就显示未知，未新增猜测厂商命令，也不宣称可读取全部耳机的左右耳/充电盒。
- 星闪：沿用 VXE 蜻蜓 R1 星闪版、ATK A9 Plus NearLink 的已有 Compx 通道。星闪不是统一电量命令；其他接收器仍需核对 ID、接口和有效回包。这次没有新增未知星闪型号的映射。
- 既有 2.4G：ROG、怒喵、ATK/VXE/VGN 的已知 Compx 版本、罗技 HID++、雷蛇、迈从、万灵、LAMZU、VAXEE、Endgame Gear，以及已收录的 AULA/AJAZZ、VGN V98、AK820 Max Plus、K1 等专用通道继续保留，实际支持程度以各型号适配说明为准。
- 手柄：XInput 只显示系统提供的电量档位，不把槽位当作具体型号。G7 Pro 专用百分比通道保留，仍待实机验证。

以前清单中的 A900、原版 AJ139 Pro、原版达摩鲨 M3、凌豹 M1 Pro，以及 A87 Pro、A98、CMK87、FL980 V2、MINI60HE、GK61 Lite、ZERO75、DK68、Gi80 CLEAR，仍缺少对应型号的专用协议。RK-G98、K03S、M68HE、JBL TOUR ONE M3 的 Smart Tx 电量也没有因本次扩展而被解决。

## 监测与诊断的共用实现

新增 `receiver_battery.py`，主程序和诊断工具调用同一型号表、接口筛选、查询和解码。设备连接并唤醒后，监测程序可直接查询；不需要先跑诊断，也没有日志导入功能。

读取失败或新设备未收录时再运行诊断：记录 HID 标识和接口能力、查询帧、回复帧、解码结果与错误，交回分析后补齐内置适配。档位与百分比在日志中分别保存。新模块只发送状态/电量查询；不配对、不改配置、不刷固件。

## 协议来源

依据公开协议事实独立实现，没有把第三方驱动代码或运行库打包进入程序。

- [G-Wolves 官方型号表](https://mouse.xyz/Config/env-models.json)和[官方网页驱动](https://mouse.xyz/)：静态核对无线 PID、新旧协议、83/8F 电量字段。型号表摘要及 SHA256 保存在 `output/wireless-battery-research-20261027.json`。网页脚本仅在内存分析，未执行，未保存完整副本。
- [HeadsetControl Nova 7](https://github.com/Sapd/HeadsetControl/blob/master/lib/devices/steelseries_arctis_nova_7.hpp)、[Nova 7P](https://github.com/Sapd/HeadsetControl/blob/master/lib/devices/steelseries_arctis_nova_7p.hpp)、[Nova 5](https://github.com/Sapd/HeadsetControl/blob/master/lib/devices/steelseries_arctis_nova_5.hpp)、[Arctis 7+](https://github.com/Sapd/HeadsetControl/blob/master/lib/devices/steelseries_arctis_7_plus.hpp)：接收器、状态查询和不同固件的档位差异。
- [HeadsetControl Cloud II](https://github.com/Sapd/HeadsetControl/blob/master/lib/devices/hyperx_cloud_2_wireless.hpp)、[HaloBattery Cloud III / II Core 的协议及抓包记录](https://github.com/HeyOkay/HaloBattery/blob/main/providers/hyperx_cloud3.py)：HyperX 各代的不同通信与状态字段。
- [NZXT 原始抓包研究与实现](https://github.com/HeyOkay/HaloBattery/blob/main/providers/nzxt.py)：Lift Elite 无线电量、电压和充电标记。
- [Keychron 协议实现](https://github.com/csutcliff/keychron-battery-dkms/blob/main/keychron_battery.c)：D028 接收器管理接口、B3/B4 状态查询。
- [Hitscan 原始抓包研究](https://github.com/sopparus/hitscan-battery)：3770:0200 的 Compx 电量帧和校验和。

公开项目的实测不等于本程序在用户硬件上已验证成功。
