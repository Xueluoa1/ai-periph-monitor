# v33 品牌型号功能支持清单

2026-10-27 补充（主程序 v1.0.2）：黑爵 AK820 Max Plus / XY 2.4G 键盘接收器 `1A2C:8FFF` 已加入电量百分比查询，待实机验证；充电状态、灯效暂未接入。该 ID 共用，不能唯一识别任意配对键盘。详见 `适配说明-AK820MaxPlus.md`。下方为原 v33 历史清单。

核对日期：2026-10-23。对应「无线外设电量监视器-UI优化版-v33.exe」。

**已接入表示存在实际读写路径，不代表每个型号和固件都经过本项目实机验证。** 必须匹配硬件 ID、接口并收到有效配置才允许写入；同品牌其他型号不自动获得支持。这里的灯光读取是配置读取，不是采样彩虹动画每一时刻的颜色。

v31 已为 v30 控制目录中 117 个鼠标 USB 标识增加 DPI 通道；剩余 1 个是充电底座，DPI 不适用。这不是 117 款独立鼠标，也不是 117 台实测设备。另增加下文的独立协议。各通道写入后都读取结果确认，没有把默认值或缓存当成设备当前值。

v32 在上述 DPI 基础上接入下表独立通道的回报率，并扩展灯光。每个型号按实际协议范围提供选项；同品牌未列出的设备不会自动套用。新增通道经过模拟回归，尚未逐型号实机写入验证。罗技部分灯区仅支持设置，界面明确标为未知；其余新增设置通过读回确认。
