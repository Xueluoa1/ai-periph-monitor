# 小鸡 G7 Pro 电量接入（同版本更新）

主程序 v1.0.2、诊断工具 v1.5.0 不变；构建标识 `20261026-gamesir`。

## 范围与依据

用户确认日志 e35f371d 的 `3537:10B9` 为小鸡 G7 Pro。接口为 MI01/Col04、Usage FFF0:0040、Input/Output 64 字节；Input RID 10/12，Output RID 0F，Feature 0。

静态核对开源项目 [gamesir-linux-tools](https://github.com/broroeror/gamesir-linux-tools) 的下列文件后，独立实现最小电量读取，不引入该项目的 Linux USB 占用、驱动切换、配置、升级或模式切换代码：

- [controller_profile.py](https://github.com/broroeror/gamesir-linux-tools/blob/main/controller_profile.py)：将 10B9 列为 G7 Pro 8K PC Championship 接收器，并路由到 `cyclone_0x12` 输入格式。程序使用用户确认的通用 G7 Pro 名称，不擅自更改具体销售版本名称。
- [reader.py](https://github.com/broroeror/gamesir-linux-tools/blob/main/reader.py)：0F F2 为维持状态上报的心跳；0x12 报文四个摇杆字节全零表示无效模式。
- [vendors/gamesir/enhanced.py](https://github.com/broroeror/gamesir-linux-tools/blob/main/vendors/gamesir/enhanced.py)：以 Report ID 为第 0 字节，第 36 字节为百分比。第 35 字节 bit0 在源码中描述为 charging/cable，因此本版仅显示电量，充电状态保留 unknown。

## 实现限制

验证：主程序 356 项、通用诊断 23 项、怒喵诊断 22 项，共 401 项回归测试通过；122 个 Python 文件语法检查通过。测试未修改实际设备设置。

- 只允许 3537:10B9 且接口、长度完全匹配；没有扩展到其他 G7 型号或只按品牌发送。
- 每次读取最多一秒，心跳间隔至少 0.5 秒；不循环重试失败命令，不写设备配置。
- 只接收长度 64、RID12、非无效模式的报文；拒绝超过 100 的百分比。有效 0% 保留，配置回复 RID10 不参与电量解码。
- 诊断工具通过共享电量目录自动执行同一读取，保存报文与结果。无需替换 Windows 驱动。
- 目前测试使用合成状态帧及真实日志接口信息，尚未收到用户设备的实机电量报文，不能称为实机验证完成。
- JBL TOUR ONE M3 / Smart Tx 电量协议仍未确认，此次未新增猜测解码。
