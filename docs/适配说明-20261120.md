## 主程序与诊断工具

两者共用同一查询实现；诊断工具会在匹配接口后自动查询并记录发送、回复、解析结果或失败原因。移除旧迈从 V3 的错误 65 字节帧构造，替换为核实的 64 字节结构。新设备读不到电量时不会显示为 0%。

已支持的型号可直接连接并唤醒后运行主程序，不需要先诊断。若未显示电量，再运行本次附带的新诊断工具，将桌面 ZIP 交回核验；不存在日志导入或离线自动逆向功能。

## 依据和验证边界

- 用户三份 ZIP 仅作为日志数据读取，不执行包内内容。
- [达摩鲨 M3 协议研究](https://github.com/Barba2k2/darmoshark-m3-configurator/blob/main/PROTOCOL.md)：接收器 Feature 通道、读取命令、旧缓存回包问题。
- [M3S 实物验证记录](https://github.com/krisgfx9/Wireless-Device-Battery-Monitor/pull/1828)及该项目 `src/drivers/darmoshark.cpp`：接收器/本体 ID 和 Windows 报告尺寸。
- [OpenMHub](https://github.com/brayanspagnol/OpenMHub)：Sinowealth 键盘内部型号和耳机读取协议；其部分设备也明确标注未实测。
- [V9 Pro 电量实现](https://github.com/rafagfran/mchose-v9-pro-battery-tray)：交叉核对耳机请求与响应字段。
- [OpenMouse 协议项目](https://github.com/OpenMouse-Project/mouse-protocol)：M HUB V3 帧结构、接收器表、共享产品 PID 限制。
- [迈从官方 M HUB](https://m-chose.com/mchose-hub/)：仅核对产品系列，不把官方支持列表视为本程序已验证。

按照协议事实独立实现。本地测试使用真实接口身份和合成电量报文，覆盖错误接口、回显、断开、越界、电量为零、校验失败、配对变化、旧缓存以及主程序/诊断路由；测试不写设备设置。具体测试数量、打包校验和文件哈希见随包 release-manifest-v1.0.2.json。新增通道仍待用户实机有效电量回复验证。
