# 任务栏合并显示

主程序版本仍为 v1.0.2，本次构建标识为 `20261111-compact-centered-hover`。

悬停面板宽度由 340 缩为 270 个逻辑像素，同时缩小图标、字号和行间距。面板中心对齐任务栏图标中心；在屏幕边缘自动避让，确保内容完整可见。

在主页打开“任务栏设备”，开启右上角“合并显示”，在“任务栏常驻设备”下拉框选择设备，然后保存。选择框只包含已选的任务栏设备；自动显示全部时包含当前设备和已保留的常驻设备。

- 合并开启后，任务栏只保留所选常驻设备的一个电量图标。
- 鼠标悬停在该图标上，显示全部已选设备的精简面板，每行仅有小图标、设备名称和百分比。
- 百分比沿用现有挂件配色：USB / 2.4G 正常电量为绿色、蓝牙正常电量为蓝色，电量不高于 10% 时为红色，未知为灰色 `--`。不把未知电量当成 0%。
- 面板不抢焦点；鼠标移入面板后保持显示，离开图标和面板约 350 毫秒后收起。设备多时可滚动。
- 常驻设备断连时保留该设备并显示未知电量，不自动换成其他设备。重新连接后恢复读数。若主动取消勾选或全局隐藏该设备，则不再作为常驻设备。
- 关闭合并显示后恢复各设备独立图标；选择和合并设置保存在原配置文件中，重启后继续生效。取消窗口不会保存编辑。
- 悬停仅复用已有电量数据，不触发额外硬件查询，不要求开启桌面挂件。独立诊断工具无需更新。

验证：合并/恢复图标、设备选择与断连、窗口保存/取消、浅深色布局、未知和低电量颜色、滚动、焦点、悬停退出以及后台窗口线程回收均已使用隔离数据检查；原生 Shell 图标位置和悬停回调也已通过临时图标验证。多屏负坐标位置已做计算测试，尚未在所有 Windows 任务栏布局与多屏缩放组合上实机验证。

Windows 接口依据：[Shell_NotifyIconW](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shell_notifyiconw)、[Shell_NotifyIconGetRect](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shell_notifyicongetrect)。
