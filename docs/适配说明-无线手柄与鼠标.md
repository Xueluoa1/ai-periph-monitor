**验证状态：**已经实现协议、自动查询和日志记录；公开资料包含部分作者的实机抓包，本项目未连接上述新增设备做实机验证。模拟回包通过不等于实机通过。接口、报告长度或产品身份不符时不发送这些查询。没有收到有效回复时显示未知／等待设备，不填入猜测的电量。

北通在充电时可能始终上报 100%；原始百分比保留，配合充电状态显示。飞智档位不会乘以 20 冒充实测百分比。赛睿 1–21 的原始码换算为 0–100%，标注“约”；原始码 0 是无效／离线，代码 1 才表示最低电量。小鸡字节 35 是接线／充电标记，暂不把它当成正在充电。

## 自动查询与诊断

插入匹配接收器并唤醒设备后，监测程序会直接调用内置只读查询；不需要先导入日志。诊断工具共用同一协议代码，自动记录查询、原始回复、解析值和失败原因，便于验证实机差异。日志导入功能保持移除。

飞智仅发送信息查询 01，不开启测试模式、原始输入模式、IMU 或控制接管。八爪鱼6使用不同协议，充电底座也使用同厂商 ID，都不归入本次适配。北通不把鲲鹏20的偏移直接扩展到阿修罗、宙斯等其他型号。小鸡不同版本的 G7 Pro、8K、充电底座和 DS4 模拟模式不能仅凭品牌名使用这套查询；原有 G7 Pro 3537:10B9 继续保留。

## 星闪、蓝牙与后续范围

VXE R1 星闪版（373B:10C9）和 ATK A9 Plus 等已核实的 FF02:0002 Compx 通道继续工作，回包校验和、状态及字段长度必须匹配。本次没有新增未经确认的星闪手柄私有命令。星闪是连接方式，不代表不同厂商共享电量命令。

蓝牙仍读取 Windows 提供的电量；XInput 通道保留系统电量档位。系统没有上报且私有协议尚未确认的型号，仍不能承诺读出电量。不能据“支持北通／飞智／小鸡”理解为支持这些品牌全部型号。

## 公开协议依据

实现独立编写，仅使用报文格式、硬件 ID 和字段语义；没有下载或执行厂商安装程序。

- 北通：[betop-battery 协议](https://github.com/oitsukiii/betop-battery/blob/main/docs/protocol.md)；[鲲鹏20 身份与公开样本](https://github.com/oitsukiii/betop-battery/blob/main/src/betop_battery/devices/betop-kp20.json)。
- 飞智八爪鱼5：[OpenFlydigi 传输](https://github.com/mkaliaha/openflydigi/blob/main/flydigi/device.py)、[信息字段](https://github.com/mkaliaha/openflydigi/blob/main/flydigi/motion.py)、[型号代码](https://github.com/mkaliaha/openflydigi/blob/main/flydigi/identity.py)。
- 飞智黑武士5 Pro：[独立驱动协议实现](https://github.com/AlexandreFournier/xpad-flydigi/blob/main/xpad_flydigi.c)、[2.4G 硬件接口](https://github.com/Chillsmeit/vader5pro-remap-driver/blob/main/docs/protocol.md)。
- 小鸡旋风2：[实机查询记录及各模式限制](https://github.com/vdemonchy/cyclone2-linux/blob/main/docs/protocol.md)。百分比标度在公开资料中主要以满电核对，仍需本项目非满电实机对照。
- 赛睿：[rivalcfg 各型号协议定义](https://github.com/flozz/rivalcfg/tree/master/rivalcfg/devices)，无线查询为 92 | 40 = D2；仅加入 `_wireless_wireless` 中的 ID。

所有新路线都有接口拒绝、请求回显、无效值、离线数据和界限测试；诊断回归覆盖自动调用与导出百分比／档位。发布包内的清单记录实际测试数量及文件校验值。
